# 🏥 Prescripto — Healthcare Appointment Management Platform

Prescripto is a full-stack MERN healthcare platform designed to simplify the process of managing medical appointments. It connects patients, doctors, and administrators through a centralized system that makes healthcare scheduling more accessible, organized, and efficient.

With role-based authentication, dynamic appointment scheduling, secure online payments, and a dedicated admin dashboard, Prescripto provides a seamless experience for every user.

## ✨ Features

### 👤 Multi-Role Authentication
- Separate access for Patients, Doctors, and Admins.
- Secure user authentication and authorization.
- Role-based dashboards and functionality.

### 🩺 Patient Portal
- Browse and explore available doctors.
- View doctor profiles and specializations.
- Book medical appointments.
- Manage and track scheduled appointments.
- Make secure online payments.

### 👨‍⚕️ Doctor Dashboard
- Manage personal profiles and availability.
- View upcoming appointments.
- Manage appointment bookings.
- Track appointment status.

### 🛠️ Admin Dashboard
- Manage doctors and patient records.
- Add and manage doctor profiles.
- Monitor appointments across the platform.
- Access centralized platform management.

### 💳 Online Payments
- Integrated Stripe and Razorpay payment gateways.
- Secure appointment payment processing.
- Payment status tracking.

### 📅 Dynamic Appointment Scheduling
- Real-time appointment slot management.
- Doctor availability-based scheduling.
- Appointment booking and cancellation management.
